# 2026-09-30

## 目标重识别（OSNet-x0_25）功能上线

- `scripts/pose_tracker_node.py` 增加目标 ReID 状态机：WAITING（首帧恰好 1 人才锁定）→ TRACKING（目标 track_id 恒为 0，此状态零 ReID 开销）→ LOST（永久搜索，OSNet 逐帧比对所有可见人，cosine ≥ reid_threshold 认回）。
- ReID 模型：torchreid 0.2.5（PyPI 版，包路径是 `torchreid.reid.utils.FeatureExtractor`，不是官方仓库的 `torchreid.utils`）。权重用 Market1501 行人重识别训练的 osnet_x0_25（gdown 从 Google Drive 下载，缓存在 `~/.cache/torch/checkpoints/osnet_x0_25_market1501.pth`）；文件缺失时回退 ImageNet 预训练。
- 阈值定为 0.75：真实照片实测不同人相似度 0.35–0.70（zidane.jpg 另一人 0.698），0.65 会误认。
- 新增 ROS 参数：`enable_reid`(true)、`reid_model_path`、`reid_threshold`(0.75)；launch 文件同步暴露。标注图目标红框 "TARGET 0" + 状态横幅。
- 依赖：系统 Python 装 torchreid + gdown + tensorboard + yacs + termcolor。
